# Backend Laravel anterior

Este directorio conserva la implementación Laravel previa para consulta y reversión durante la transición. El flujo actual del proyecto inicia el backend Django de `django_backend/`; Laravel no se arranca desde `ejecutar.bat`.

La arquitectura vigente, los pasos de instalación y la importación controlada de datos están documentados en el [README principal](../README.md) y en [docs](../docs/README.md).
